## 🚀 Como publicar

**Netlify (mais fácil):** arraste a pasta com os dois arquivos em [app.netlify.com/drop](https://app.netlify.com/drop).

**GitHub Pages:**
1. suba os arquivos no repositório
2. Settings → Pages → Branch: `main` / root → Save
3. o link aparece em alguns minutos

> ⚠️ mantenha `index.html` e o PDF na **mesma pasta** — o botão "Currículo" procura o PDF ali do lado.
